# 六级过线笔记

大学英语六级（CET-6）备考页面，目标 425。纯前端，手机电脑都能用，离线可看。

**在线地址** → https://vagee9157.github.io/cet6/

## 有什么

| 板块 | 内容 |
|---|---|
| 首页 | 710 分拆解条（点一段看策略）、今天的四件事、各模块考点与解题套路（听力 / 阅读 / 写作 / 翻译 / 词汇 / 考试结构） |
| 单词 | 260 个高频词按 9 个主题分组，翻转闪卡 + 朗读，认识 / 模糊 / 不认识三档，不认识的进生词本 |
| 听读 | 听力（长对话 / 篇章 / 讲座，浏览器 TTS 朗读，可调语速，交卷后看原文）、阅读（仔细阅读 / 段落匹配 / 选词填空，点选作答，计时） |
| 写译 | 写作题目 + 提纲 + 范文（加分句高亮）；翻译原文 + 关键词 + 参考译文 |
| 我的 | 生词本、错题本、进度 |
| 模拟卷 | `paper.html`：从题库随机组一份完整试卷（写作 + 听力 + 阅读 + 翻译 + 答题卡 + 答案与听力原文），A4 排版，可打印 / 存 PDF；`?seed=` 固定卷号 |

## 内容说明

- 六级真题版权归教育部教育考试院，本站**不收录历年原卷**；练习题按真题的题型、篇幅、难度和出题套路自编。
- 考试结构、分值、时间依据全国大学英语四、六级考试官网公布的考试大纲。
- 听力由浏览器语音合成朗读，与真题的美音播音员有差异。
